# 交互式移动与调整大小

许多应用窗口都带有可交互的 UI 元素，用户可以用它们来拖动或调整窗口大小。默认情况下，许多 Wayland 客户端都期望由自己负责窗口装饰，以提供这些可交互元素。在 X11 上，应用窗口可以在屏幕上的任意位置自行定位，并借此实现这些交互。

然而，Wayland 有一个刻意为之的设计特征：应用窗口并不知道自己在屏幕上的确切位置，也不知道自己相对于其他窗口的位置。这一决定赋予了 Wayland 合成器更大的灵活性——窗口可以同时在多个位置显示、被布置在 VR 场景的三维空间中，或者以任何其他新颖的方式呈现。Wayland 被设计成通用且广泛适用于众多设备与形态的协议。

为了平衡这两方面的设计需求，XDG 顶层窗口提供了两个请求，可以用来请求合成器开始一次交互式移动或调整大小操作。接口中相关的部分如下：

```xml
<request name="move">
  <arg name="seat" type="object" interface="wl_seat" />
  <arg name="serial" type="uint" />
</request>
```

与上一章介绍的弹出窗口创建请求类似，你必须提供一个输入事件 serial 才能启动交互式操作。例如，当你收到鼠标按键按下事件时，可以使用该事件的 serial 来开始一次交互式移动操作。接下来合成器会接手，在其内部坐标空间中为你的窗口开始一次交互式操作。

调整大小则稍微复杂一些，因为需要指定窗口的哪些边或角参与了该操作：

```xml
<enum name="resize_edge">
  <entry name="none" value="0"/>
  <entry name="top" value="1"/>
  <entry name="bottom" value="2"/>
  <entry name="left" value="4"/>
  <entry name="top_left" value="5"/>
  <entry name="bottom_left" value="6"/>
  <entry name="right" value="8"/>
  <entry name="top_right" value="9"/>
  <entry name="bottom_right" value="10"/>
</enum>

<request name="resize">
  <arg name="seat" type="object" interface="wl_seat" />
  <arg name="serial" type="uint" />
  <arg name="edges" type="uint" />
</request>
```

除此之外，它的工作方式大同小异。如果用户点击并沿着窗口左下角拖动，你可能希望发送一个交互式调整大小请求，带上相应的 seat 与 serial，并把 edges 参数设为 bottom_left。

还有一个请求，是客户端完整实现客户端侧窗口装饰所必需的：

```xml
<request name="show_window_menu">
  <arg name="seat" type="object" interface="wl_seat" />
  <arg name="serial" type="uint" />
  <arg name="x" type="int" />
  <arg name="y" type="int" />
</request>
```

当点击窗口装饰时，通常会弹出一个提供窗口操作（例如关闭或最小化窗口）的上下文菜单。对于由客户端管理窗口装饰的客户端来说，这个请求用于将客户端驱动的交互与合成器驱动的元操作（例如最小化窗口）连接起来。如果你的客户端使用客户端侧装饰，你可以为此目的使用该请求。

## xdg-decoration

在讨论客户端侧装饰的行为时，最后一个值得一提的细节，是决定是否使用它们的协商协议。不同的 Wayland 客户端与服务端可能对使用服务端侧还是客户端侧窗口装饰有着不同的偏好。为了表达这些意图，使用了一个协议扩展：`xdg-decoration`。它可以在 wayland-protocols 中找到。该协议提供了一个全局对象：

```xml
<interface name="zxdg_decoration_manager_v1" version="1">
  <request name="destroy" type="destructor" />

  <request name="get_toplevel_decoration">
    <arg name="id" type="new_id" interface="zxdg_toplevel_decoration_v1"/>
    <arg name="toplevel" type="object" interface="xdg_toplevel"/>
  </request>
</interface>
```

你可以把 `xdg_toplevel` 对象传入 `get_toplevel_decoration` 请求，以获得一个具有如下接口的对象：

```xml
<interface name="zxdg_toplevel_decoration_v1" version="1">
  <request name="destroy" type="destructor" />

  <enum name="mode">
    <entry name="client_side" value="1" />
    <entry name="server_side" value="2" />
  </enum>

  <request name="set_mode">
    <arg name="mode" type="uint" enum="mode" />
  </request>

  <request name="unset_mode" />

  <event name="configure">
    <arg name="mode" type="uint" enum="mode" />
  </event>
</interface>
```

`set_mode` 请求用于表达客户端的偏好，而 `unset_mode` 用于表达无偏好。随后合成器会通过 `configure` 事件告知客户端是否使用客户端侧装饰。更多细节请查阅完整的 XML。
