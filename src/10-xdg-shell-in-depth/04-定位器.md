# 定位器

当我们几页之前介绍弹出窗口时，我们提到创建弹出窗口时必须提供一个定位器对象。我们当时请你别担心它、直接用默认值就好，因为它是个复杂的接口，而且与当时的主题无关。现在，我们将深入探究这个复杂的接口。

当你打开一个弹出窗口时，它会被显示在一个窗口系统中，而该窗口系统有一些你的客户端并不知情的约束。例如，Wayland 客户端并不知道自己的窗口显示在屏幕上的哪个位置。因此，如果你右键点击一个窗口，客户端并不掌握必要的信息去判断由此产生的弹出窗口是否会被推出屏幕边缘。定位器的设计正是为了解决这些问题：它允许客户端就弹出窗口如何移动或调整大小指定某些约束，然后由完全掌握实际情况的合成器来最终决定如何安置。

# 基础

```xml
<request name="destroy" type="destructor"></request>
```

这会在你用完后销毁定位器。你可以在弹出窗口创建之后再调用它。

```xml
<request name="set_size">
  <arg name="width" type="int" />
  <arg name="height" type="int" />
</request>
```

set_size 请求用于设置正在创建的弹出窗口的大小。

所有使用定位器的客户端都会用到这两个请求。现在，让我们进入有趣的部分。
