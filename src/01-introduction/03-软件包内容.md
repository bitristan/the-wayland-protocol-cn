# Wayland 软件包的内容

当你在自己所用的 Linux 发行版中安装 “wayland” 时，最终你很可能会得到 freedesktop.org 发布的 libwayland-client、libwayland-server、wayland-scanner 和 wayland.xml。它们分别可能位于 /usr/lib 和 /usr/include、/usr/bin 以及 /usr/share/wayland/。这个软件包是 Wayland 协议最流行的*实现*，但它并不是唯一的实现。第 3 章会详细讲解 Wayland 的这个实现；本书其余内容同样适用于任何实现。

## wayland.xml

Wayland 协议由 XML 文件定义。如果你找到 “wayland.xml”，并用自己喜欢的文本编辑器打开它，就会看到 Wayland “核心”协议的 XML 规范。这是一个高层协议——建立在我们将在下一章讨论的线上协议之上。本书的大部分篇幅都致力于解释这个文件。

## wayland-scanner

“wayland-scanner” 工具用于处理这些 XML 文件并从中生成代码。最常见的实现就是你现在正在查看的这个，它可用于从 wayland.xml 之类的 XML 文件生成 C 头文件和胶水代码。针对其他编程语言也存在别的扫描器，例如 wayland-rs（Rust）、waymonad-scanner（Haskell）等等。

## libwayland

libwayland-client 和 libwayland-server 这两个库分别为连接的每一端提供了线上协议的实现。此外，它们还提供了一些常用的实用工具，比如处理 Wayland 数据结构的工具、一个简单的事件循环等等。另外，这些库中还包含一份由 `wayland-scanner` 生成的核心 Wayland 协议的预编译副本。
