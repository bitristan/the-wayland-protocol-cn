# XDG shell 基础

XDG（cross-desktop group，跨桌面组）shell 是 Wayland 的一个标准协议扩展，它描述了应用窗口的语义。它定义了两个 `wl_surface` 角色：“toplevel”（顶层窗口），用于你的顶层应用窗口；以及 “popup”（弹出窗口），用于上下文菜单、下拉菜单、工具提示之类的东西——它们是顶层窗口的子级。把它们组合起来，你就能构成一棵表面树，顶层是顶层窗口，叶子则是弹出窗口或附加的顶层窗口。该协议还定义了一个 *定位器*接口，它用于在只掌握窗口周围事物有限信息的情况下帮助定位弹出窗口。

xdg-shell 作为一个协议*扩展*，并未定义在 `wayland.xml` 中。你会在 `wayland-protocols` 包里找到它。在你的系统上，它大概安装在类似 `/usr/share/wayland-protocols/stable/xdg-shell/xdg-shell.xml` 这样的路径下。

## xdg_wm_base

`xdg_wm_base` 是该规范定义的唯一全局对象，它提供了用于创建你所需的其他各个对象的请求。最基本的实现从处理 “ping” 事件开始——当合成器发送它时，你应当及时用一个 “pong” 请求来回应，以表明你并没有陷入死锁。另一个请求用于创建定位器，也就是前面提到的那些对象，我们把关于它们的细节留到第 10 章。我们首先想深入了解的请求是 `get_xdg_surface`。
